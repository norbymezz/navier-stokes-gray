# Mathematical formulation

This document fixes the terminology used by the project before we commit to a particular vessel or CFD implementation.

## 1. Continuous physical model

The hydrodynamic core is the incompressible Navier–Stokes system

```math
\partial_t\mathbf u+(\mathbf u\cdot\nabla)\mathbf u
=-\rho^{-1}\nabla p+\nu\nabla^2\mathbf u+\mathbf f,
```

```math
\nabla\cdot\mathbf u=0.
```

The first transport field is a passive scalar

```math
\partial_t c+\mathbf u\cdot\nabla c=D\nabla^2c.
```

The passive scalar is a diagnostic field, not yet an ionic species.

## 2. Stokes limit and reversibility

With characteristic velocity `U`, length `L` and kinematic viscosity `nu`,

```math
Re=\frac{UL}{\nu}.
```

For `Re << 1`, inertial terms are negligible relative to viscous terms. The momentum equation becomes linear in velocity for prescribed forcing/boundaries.

The useful experimental statement is kinematic reversibility: if a boundary-motion protocol is performed and then exactly reversed, particle trajectories retrace in the ideal Stokes limit.

This does not imply that every concentration pattern will be recovered exactly in a real experiment or numerical model. Diffusion, molecular noise and numerical dissipation are irreversible mechanisms and must be measured separately.

## 3. Chaotic advection versus turbulence

The project explicitly separates two notions:

- **chaotic advection**: complicated Lagrangian trajectories generated by time-dependent or spatially nontrivial laminar flow;
- **turbulence**: inertial, broadband, dynamically coupled fluctuations of the velocity field.

A topologically complicated stirring protocol can create chaotic advection even when `Re` is very small. This is useful because the effect of geometry/topology can be studied before inertia becomes important.

## 4. Boundary identifications as topological operations

The principal mathematical use of topology is to define how boundaries are identified.

### Ordinary periodicity

```math
(x+L_x,y)\sim(x,y).
```

### Orientation-reversing identification

A representative twisted map is

```math
(x,y+L_y)\sim(L_x-x,y).
```

For a vector field, the geometric map must also act on vector components. For a reflection of the `x` coordinate, a consistent map has the schematic form

```math
u_x(x,L_y)=-u_x(L_x-x,0),
```

```math
u_y(x,L_y)=u_y(L_x-x,0).
```

Scalar fields transform without the sign change induced by vector reflection:

```math
c(x,L_y)=c(L_x-x,0).
```

The exact map used by the numerical discretization must preserve incompressibility and flux continuity.

## 5. Spatial-step description

The discrete index

```math
n=0,1,2,\ldots
```

labels a transformation stage, not necessarily physical time.

A general state can be written

```math
X_n=(\mathbf u,p,c,\phi,\rho_e,T,\ldots)_n.
```

The sequence acts as

```math
X_{n+1}=\mathcal T_n[X_n].
```

A transformation may modify geometry, a boundary map, forcing, or a composition rule while the underlying PDE remains explicit.

## 6. D2 and D3

`D2` and `D3` are working labels, not yet fixed geometries.

`D2` denotes a binary operation such as:

- split/recombine;
- exchange of two channels or stream labels;
- inversion/reflection;
- binary reorientation between planes.

`D3` denotes a triadic operation such as:

- three-way branch/recombine;
- cyclic reorientation of three channels or labels;
- a three-strand braid step;
- a three-plane spatial operation.

A future implementation must specify each operator as a map on both state variables and boundaries.

## 7. Braid representation

For three strands, use the braid generators

```math
\sigma_1: 1\leftrightarrow2,
\qquad
\sigma_2: 2\leftrightarrow3.
```

with inverses `sigma_1^-1`, `sigma_2^-1` indicating opposite crossing orientation.

This lets us reason about exchange sequences without prematurely choosing a double helix, a physical braid, or a particular glass topology.

## 8. Gray-ordered perturbations

Let a bit vector encode controlled features:

```math
g_n\in\{0,1\}^m.
```

A Gray sequence satisfies

```math
d_H(g_n,g_{n+1})=1,
```

where `d_H` is Hamming distance.

This is an experimental-design device: only one modeled feature changes between adjacent cases.

Possible features include boundary twist, D2/D3 activation, forcing direction, curvature class, external field activation, or a selected braid generator.

## 9. Recursive composition

A Fibonacci-like rule may organize the composition of operators without claiming that the fluid obeys a Fibonacci law.

For instance,

```math
\mathcal T_n=D_2^{a_n}D_3^{b_n},
```

with

```math
(a_{n+1},b_{n+1})=(a_n+a_{n-1},b_n+b_{n-1}).
```

Alternative compositions should be tested against simpler periodic and random controls.

## 10. Diagnostics

The minimum diagnostics are:

### Divergence error

```math
\epsilon_{div}=\|\nabla\cdot\mathbf u\|.
```

### Kinetic energy

```math
E=\frac12\int_\Omega|\mathbf u|^2\,dV.
```

### Vorticity and enstrophy

```math
\boldsymbol\omega=\nabla\times\mathbf u,
```

```math
\mathcal Z=\frac12\int_\Omega|\boldsymbol\omega|^2\,dV.
```

### Scalar variance

```math
V_c=\int_\Omega(c-\bar c)^2\,dV.
```

### Reversibility error

```math
E_R=\frac{\|c_{final}-c_{initial}\|}{\|c_{initial}\|}.
```

### Balance checks

Mass, scalar mass, momentum input, pressure work and viscous dissipation must be tracked explicitly.

## 11. Later electrokinetic extension

When the passive-scalar stage is validated, introduce species concentrations `c_i` with Nernst–Planck flux

```math
\mathbf J_i=c_i\mathbf u-D_i\nabla c_i-\mu_i z_iF c_i\nabla\phi,
```

and Poisson equation

```math
-\nabla\cdot(\epsilon\nabla\phi)=\rho_e.
```

The fluid momentum equation then receives electrical body forces when appropriate.

The ionic product of water remains an equilibrium relation; the spatially transported quantities are concentrations, electrochemical potentials, ionic fluxes, polarization and charge density.

## 12. Validation order

1. periodic laminar benchmark;
2. reversible forward/reverse protocol at low `Re`;
3. passive-scalar transport benchmark;
4. twisted boundary map;
5. D2/D3 elementary maps;
6. braid sequences;
7. Gray-ordered case sweep;
8. Reynolds-number sweep;
9. recursive compositions;
10. electrokinetic extension.

Every new layer must preserve or intentionally alter the previously verified balances.
