# navier-stokes-gray

A numerical research sandbox for studying how **controlled spatial transformations and boundary identifications** interact with incompressible flow, scalar transport, reversibility, inertia, and eventually electrokinetic transport.

The project starts from standard fluid mechanics and adds topological operations only when they can be stated precisely as geometry, boundary conditions, or transformations of the state variables.

## Core question

Can a sequence of spatial transformations be used to control how velocity, pressure, concentration and charge-density fields are transported, separated, recombined and compared, while keeping the governing equations and boundary conditions explicit?

The working philosophy is:

1. start from a validated flow problem;
2. add one controlled change at a time;
3. preserve measurable invariants and balances where the physics requires them;
4. distinguish geometric/topological effects from inertial and turbulent effects;
5. only then add ionic transport and electric fields.

## 1. Baseline equations

For an incompressible Newtonian fluid,

```math
\frac{\partial \mathbf u}{\partial t}
+(\mathbf u\cdot\nabla)\mathbf u
=-\frac{1}{\rho}\nabla p
+\nu\nabla^2\mathbf u
+\mathbf f,
```

```math
\nabla\cdot\mathbf u=0.
```

A passive concentration field is initially represented by

```math
\frac{\partial c}{\partial t}
+\mathbf u\cdot\nabla c
=D\nabla^2c.
```

This passive scalar is deliberately used before ionic chemistry: it lets us test transport, mixing, reversibility and boundary transformations without conflating them with electrochemistry.

## 2. Low Reynolds number and reversibility

At very small Reynolds number, inertia is negligible and the momentum equation approaches the Stokes system,

```math
0=-\nabla p+\mu\nabla^2\mathbf u+\mathbf f,
```

with incompressibility preserved.

If the boundary forcing is reversed quasistatically and diffusion/numerical error are negligible, the velocity field is kinematically reversible. This gives us a stringent validation experiment:

```text
forward sequence  S1, S2, ..., SN
reverse sequence  SN^-1, ..., S2^-1, S1^-1
```

A reversibility error can be measured as

```math
E_R=
\frac{\|c_{final}-c_{initial}\|}
{\|c_{initial}\|}.
```

In the ideal reversible limit, `E_R -> 0`.

Important distinction: geometrically complicated trajectories can occur even at low Reynolds number. **Chaotic advection is not turbulence.** This distinction is useful because it lets us separate complexity generated by geometry/topology from complexity generated by inertia.

## 3. Why topology enters

The project does not assume that a literal Klein bottle, Möbius strip or helix is physically privileged.

Instead, these objects motivate precise operations such as:

- periodic identification;
- orientation reversal;
- branch/recombine operations;
- braid-like exchanges;
- rotations between planes;
- recirculation without introducing an artificial sharp corner;
- matching boundary conditions across identified surfaces.

For example, ordinary periodicity can be written as

```math
(x+L_x,y)\sim(x,y).
```

A twisted identification can instead use

```math
(x,y+L_y)\sim(L_x-x,y).
```

The associated vector field must transform consistently with the geometric reflection. This is the mathematically useful content of a Klein-like identification: not the decorative shape, but the boundary map.

## 4. Discrete spatial step

We introduce a discrete index

```math
n=0,1,2,\ldots
```

that is not necessarily physical time. It labels successive spatial transformations or experimental/simulation stages.

The state at step `n` may be represented schematically as

```math
X_n=
\begin{pmatrix}
\mathbf u\\
p\\
c\\
\phi\\
\rho_e\\
T
\end{pmatrix}_n,
```

with a transformation

```math
X_{n+1}=\mathcal T_n X_n.
```

At the initial stage, only the fluid and passive-scalar components are active.

## 5. D2 and D3 as abstract operators

`D2` and `D3` are provisional names for two classes of spatial operation.

- `D2`: two-way split/recombine, exchange, inversion or binary orientation operation.
- `D3`: three-way branch/recombine or triadic orientation operation.

They are intentionally abstract at first. A later implementation may realize them using channels, rotations, braid generators, boundary maps, or combinations thereof.

The objective is to define their action on the state and on the boundaries before committing to any one physical vessel geometry.

## 6. Braid representation

For three strands or stream labels, braid-group generators provide a compact way to represent exchanges:

```math
\sigma_1:\;1\leftrightarrow2,
\qquad
\sigma_2:\;2\leftrightarrow3.
```

The inverses distinguish crossing orientation:

```math
\sigma_1^{-1},\qquad \sigma_2^{-1}.
```

A sequence such as

```math
\sigma_1\sigma_2\sigma_1^{-1}\sigma_2
```

can therefore be specified algebraically before selecting a particular 3-D channel shape.

A double helix is only one possible geometric realization of such a sequence; a braid is the more general abstraction.

## 7. Gray code: one controlled change at a time

A Gray-code ordering is useful because adjacent states differ in exactly one bit:

```text
0000 -> 0001 -> 0011 -> 0010 -> ...
```

Bits may encode controlled changes such as:

```text
bit 0 : twist / no twist
bit 1 : D2 / D3 choice or activation
bit 2 : ordinary / orientation-reversing boundary map
bit 3 : external field off / on
```

The exact assignment will evolve.

The scientific role of Gray ordering is experimental design: consecutive simulations differ by one controlled operation, making changes in observables easier to attribute.

## 8. Fibonacci-style composition

Fibonacci is not assumed to be a law of the fluid. It is investigated as a possible **rule for composing operators**.

For example,

```math
\mathcal T_n=D_2^{a_n}D_3^{b_n},
```

with

```math
(a_{n+1},b_{n+1})
=(a_n+a_{n-1},\,b_n+b_{n-1}).
```

This gives a simple step counter `n -> n+1` while the internal composition of operations evolves recursively.

That separation between the step index and the complexity of the operation is one of the concepts to test.

## 9. Observable quantities

The first numerical experiments will monitor quantities such as kinetic energy,

```math
E=\frac12\int_\Omega |\mathbf u|^2\,dV,
```

vorticity,

```math
\boldsymbol\omega=\nabla\times\mathbf u,
```

an enstrophy-like measure,

```math
\mathcal Z=\frac12\int_\Omega|\boldsymbol\omega|^2\,dV,
```

and scalar variance,

```math
V_c=\int_\Omega(c-\bar c)^2\,dV.
```

Additional diagnostics will include mass conservation, divergence error, pressure loss, reversibility error and numerical convergence.

## 10. Planned numerical progression

### Stage A — validated reversible baseline

- incompressible 2-D flow;
- passive scalar;
- low Reynolds number;
- periodic boundaries;
- forward/reverse forcing experiment;
- convergence and conservation checks.

### Stage B — topology without turbulence

- twisted/orientation-reversing boundary identification;
- D2/D3 operators;
- braid-like transformations;
- compare ordinary periodic, toroidal and Klein-like identifications;
- test for chaotic advection while `Re << 1`.

### Stage C — inertial transition

Sweep Reynolds number upward while holding geometry and forcing protocol fixed.

The goal is to determine when deviations from reversible/Stokes behavior arise from inertia rather than from the topology itself.

### Stage D — Gray-ordered experiments

Encode the available transformations as bits and traverse configurations in Gray order so that one feature changes between adjacent simulations.

### Stage E — recursive operator sequences

Test Fibonacci-style or other recursive operator schedules after the elementary operators are validated individually.

### Stage F — ionic transport

Only after the hydrodynamic framework is stable, replace the passive scalar with ionic species and add Poisson–Nernst–Planck transport.

For species `i`,

```math
\mathbf J_i
=c_i\mathbf u
-D_i\nabla c_i
-\mu_i z_i F c_i\nabla\phi,
```

coupled to

```math
-\nabla\cdot(\epsilon\nabla\phi)=\rho_e.
```

At that stage the quantities of interest include ionic concentration gradients, electric potential and space-charge density.

## 11. What is hypothesis and what is established physics?

Established framework used here:

- incompressible Navier–Stokes/Stokes flow;
- advection-diffusion;
- Reynolds-number scaling;
- kinematic reversibility in the Stokes limit;
- periodic/twisted boundary maps;
- braid representations;
- Poisson–Nernst–Planck electrokinetics.

Research hypotheses to test:

- whether particular D2/D3 sequences produce useful controllable transport effects;
- whether orientation-reversing boundary maps improve separation/recombination protocols;
- whether Gray-ordered perturbations reveal useful causal structure in the simulations;
- whether recursive operator schedules produce measurable advantages over simpler periodic schedules;
- whether the same architecture remains useful after ionic transport is activated.

No energetic gain is assumed a priori. Any claim of useful separation, stored electrochemical potential or recoverable work must follow from explicit balances and numerical/experimental measurement.

## 12. Immediate implementation target

The first executable target is deliberately modest:

```text
2-D incompressible flow
+ passive scalar
+ periodic boundaries
+ one twisted-boundary option
+ low-Re forward/reverse protocol
+ Reynolds-number sweep
+ quantitative diagnostics
```

Once that is verified, D2/D3 and Gray-controlled transformations can be added without changing the validation foundation.
